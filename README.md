# WaferAI 4.11.2

Android 晶圆缺陷识别、良率分析与 AI 助手毕业设计。versionCode 50。

[下载安装包](https://github.com/qingjiu1021-love/WaferAI/releases/latest) · [账号与帮助中心](https://waferai-help.sparsefirefly.chatgpt.site/account)

支持 Android 8.0 及以上的 arm64-v8a / x86_64。手机本地晶圆分析无需电脑服务，测试包沿用此前签名，可直接覆盖安装，无需先卸载。

修复从 AI 切到数据时对话历史侧栏在滑动期间短暂覆盖数据页的问题。各底部标签页在自己的边界内绘制。

## 4.11.1 本地更新

导入晶圆后可从左上角返回晶圆工作台，已保存的晶圆仍可从历史记录打开。晶圆测试支持暂停与继续，最近 30 次完整测试和回放独立保存，重启后仍可查看晶圆图、模拟读数、AI 分类和图表，或导出带原完成时间的 PDF。

## 4.11.0 本地更新

晶圆页新增「晶圆测试」。模拟测量按漏电流上限判定，历史结果回放支持 WM-811K 样本和已载入晶圆。逐颗显示进度，完成后运行本地 CNN，提供异常定位、良率图表和带来源标记的 PDF。工作台结果在本次 App 运行期间可查看，PDF 可另存到手机。

## 4.10.5 本地更新

晶圆页新增「如何获取晶圆源文件」图文指引。数据文件路径展示单片导出、JSON 示例与手机文件选择器。晶圆图片路径使用同一张 WM-811K 练习图说明获取、裁剪、网格校准和结果核对。可在指引中保存练习文件或打开公开来源。

开屏动画从应用第一帧开始。启动窗口沿用同色底幕，晶圆扫描使用 Android 原生矢量动画。首页在扫描期间准备，其他标签页和底栏折射在进入首页后开始绘制。

## 4.10.3 本地更新

五个主页在首屏绘制后分批准备，切页保留页面布局和滚动位置。滑动使用可中断的弹簧，连续点击时从当前画面接着移动。悬浮底栏在滑动时保持透光，停稳后恢复低分辨率实时折射。晶圆总览只在本机数据发生变化时重新读取。

## 4.10.1 本地更新

五个底部选项卡支持点按和拖动。选中胶囊按下抬升、拖动拉伸，松手后回到选中的标签。滑动模式下新旧页面同时整页滑动，主题中的淡入选项仍可使用。

浮动底栏实时取样页面背景。Android 13 及以上使用折射和模糊，Android 12 使用模糊，更早的系统使用透明渐变。常用按键、图标按键、筛选项和菜单采用统一的玻璃样式。交互参考 [FlClash](https://github.com/chen08209/FlClash/commit/7c9627fffb35f2615fbfaa64b4b3a0c5834c52ed)。

## 4.10.0 本地更新

## 4.9.0 本地更新

流畅度优化：同一片的摘要、报告图表与连通区共用计算结果；统计行列与分区一次扫描，减少临时列表。晶圆位图、异常坐标和大聚集区边界在后台准备，缩放时仅绘制可见网格线。拖动图像仅使绘图和缩放读数更新。

聊天输入不再触发整个主界面更新，历史消息采用稳定标识，等待计时独立刷新；本地问答与在线请求组装移到后台。已保存训练模型的反序列化也移出启动界面线程。保留主题、玻璃底栏和开启动画的现有设置。详见 [性能优化与验收](docs/性能优化与验收.md)。先交付本地测试包，GitHub 发布由用户另行选择。

## 4.8.0 本地更新

导入或打开历史晶圆后自动生成整片摘要，包含尺寸、芯片计数、良率和可点击的突出发现。支持将低良率提示、分区不合格率最高区域和最大四连通缺陷聚集区定位到晶圆图，自动缩放并高亮对应不合格芯片，清除后恢复普通查看。

专用 AI 解析提供快速解读、工程排查、论文说明、图表解释四种模板，选择会保留到下次启动。解析按结构化事实 ID 返回，本机核对事实和来源编号并填入统计值；模型自由文本出现数字、百分号或非法结构时不保存新解析，保留原有结果和离线摘要。匹配知识库条目只作为参考，来源随解析保存并进入 PDF。事实引用核对不代表对模型解释、工艺根因或结论的正确性认证。

本版先交付本地测试包，是否发布 GitHub 仍由用户逐版确认。详细口径见 [摘要和证据解析说明](docs/摘要与证据解析.md)。

## 使用

1. 安装独立版 APK；支持 64 位 Android 8.0 及以上（arm64-v8a / x86_64）。
2. 点击“载入演示晶圆”或选择自己的 JSON，点击“识别缺陷类型”。内置示例良率为 85.71%。
3. 历史、批次和导出均使用手机数据。旧电脑记录需要通过对应 JSON 重新导入，电脑原数据不会被删除。
4. 如需在线解析，在“AI 设置”中填写 DeepSeek API 密钥并保存，然后在已识别晶圆下点击“DeepSeek 解析（联网）”。每次请求由用户主动触发，可能产生 API 费用。
5. 保存过的解析可离线查看，并随 PDF 导出；密钥使用 Android Keystore 加密，不写入安装包或报告。

完整安装、配置、手机数据库和验证范围见 [独立运行版与 DeepSeek 解析](docs/独立运行版与DeepSeek解析.md)。当前电脑也可运行项目根目录“安装独立版到手机.bat”，安装完成后即可拔掉 USB。
