每一步，都有答案

从导入第一张晶圆，到模型对话与检测报告，快速找到应用常见问题的解决方法。

支持哪些晶圆数据格式？

晶圆页可导入 STDF、ATDF、CSV、JSON 和 Parquet。JSON 需包含 lot_code、wafer_code 和二维 map。矩阵值 0 表示非芯片，1 表示合格，2 表示不合格。不同文件的字段和测试编码需按导入说明整理。

良率如何计算？

良率 = 合格芯片数 ÷（合格芯片数 + 不合格芯片数）。非芯片区域不参与。批次和总体良率按有效芯片数加权，并非各片良率的简单平均。

图片导入后识别不准确怎么办？

使用清晰、正视的晶圆图，裁掉边框、图例和文字，检查网格校准及颜色对应。图片中的颜色需要先转为芯片状态，不等同于任意显微照片的材料缺陷检测。

手机没有网络还能使用吗？

已安装模型的晶圆分类、可视化、良率统计和已保存的知识可在本机使用。在线大模型、账号验证、联网资料搜寻和网页帮助需要网络。

如何添加可以自由对话的 AI？

在 AI 页的模型选择中添加服务商或兼容接口，填写属于该服务的地址、密钥和模型 ID。联网模型支持日常聊天、写作、编程和晶圆分析。离线基础助手为规则与知识检索工具，不具备通用大模型能力。

AI 提示密钥无效或没有模型权限怎么办？

确认密钥、接口地址和模型均属于同一供应商，检查余额和模型权限。网页聊天订阅通常不能代替 API 权限。先测试连接，再尝试文本消息。图片需要支持视觉输入的模型。

模型得分很高就代表检测一定正确吗？

模型得分表示分类倾向，不等于经过校准的正确概率。应同时查看原始图、预测类别、异常位置和电测记录，不能仅凭 AI 输出判定制造根因。

怎样导出检测成果？

打开晶圆记录可进行检测并导出 PDF，在历史记录中可导出筛选后的 CSV。数据页提供良率分布、批次对比和趋势入口。导出文件保存在你选择的位置。

验证码收不到或无法第三方登录怎么办？

检查邮箱拼写、垃圾邮件和国家区号。当前开发收件箱模式不会发送真实短信或邮件。微信、QQ、Facebook 和 Telegram 登录须由维护者开通对应开发者服务；未开通时可使用已配置的邮箱或手机号渠道。

密码忘记了怎么办？

在账号页选择找回密码，使用注册邮箱或手机号接收验证码，再设置新密码。重置后旧登录会话会失效。第三方授权账号请在对应平台找回，不要向任何人提供验证码。

登录后能同步晶圆、聊天和模型密钥吗？

当前账号用于身份认证和帮助中心，不自动上传或同步本机晶圆、聊天、训练样本或 API 密钥。切换账号不会切换本机工作空间，使用共享设备时请妥善管理本机数据。

如何备份、重置设置和注销账号？

我的 → 备份与恢复可导出晶圆备份。主题页底部恢复默认设置会立即生效，保留晶圆及已保存模型配置。账号页可退出或注销账号，注销不删除设备上的晶圆、聊天和导出文件。
