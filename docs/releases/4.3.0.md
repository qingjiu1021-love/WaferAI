账号与更新功能：

- 支持添加、切换与移除已登录账号，登录凭据在设备上加密保存；切换时联网验证会话。
- 支持验证码绑定手机号或邮箱，为新登录方式设置密码；联系方式不自动合并到其他账号。
- “我的 → 关于”新增检查版本更新、GitHub 项目入口与安装包下载。
- “我的”底部移除重复的 WaferAI 名称与版本，仅在“关于”显示版本。

安装说明：支持 Android 8.0 及以上的 arm64-v8a / x86_64 设备。此包沿用此前的测试签名，可覆盖安装，不需卸载旧版本。

账号服务：ChatGPT 授权入口已提供。真实邮箱、短信、微信、QQ、Facebook 与 Telegram 渠道仍需维护者配置服务商凭据；未开通的发送服务不会伪装为发送成功。本机晶圆、聊天记录不随账号切换或同步。
