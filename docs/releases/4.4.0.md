个人资料与联网对话：

- “我的 → 编辑头像与昵称”支持选择照片、移除头像和修改昵称，按当前账号保存在设备，访客单独保存，重启后保留。
- AI 输入框新增持久保存的“联网搜索”开关；开启后使用当前问题搜索网页，并可补充已启用的搜索插件。
- 在线模型收到检索到的标题、网址和网页摘要；回答下方保留来源链接。本机基础助手可展示搜索摘要。
- 对话显示准备、搜索、等待模型回复、保存等实际阶段与耗时。接口没有提供真实思考百分比时不显示虚构进度。
- 旧聊天记录继续可读，搜索来源随新对话保存在本机。

使用说明：通用搜索默认使用 Bing 的公开 RSS 搜索结果，结果和可用性取决于手机网络及上游服务；不保证搜索成功或完整覆盖所有网站。搜索只发送本次问题，不发送附件与记忆。网络故障或没有结果时会明确提示；在线模型需要用户自己的有效 API 配置。本版未代用户测试真实付费模型调用。

头像和昵称属于本机显示资料，不自动同步到服务器，也不会修改 QQ 等第三方平台的原始资料。请覆盖安装，无需卸载旧版。
