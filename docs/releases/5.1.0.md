## WaferAI 5.1.0

- 导入文件时先预览来源、批次、晶圆编号、网格尺寸和良率，确认后保存。数据来源随历史记录、统计 CSV、PDF 和备份保留。
- 「数据 → 批次汇总 → 批次晶圆」新增同批失效叠加图。可选择 2～30 片坐标可对齐的晶圆，点选一个位置查看各片的合格状态并打开原图。
- 「测试仿真与结果回放」支持用同一组模拟漏电流读数比较两个上限，并在 PDF 中标明数据来源。WM-811K 回放沿用数据集原有合格状态。
- 「近期检测记录」按本机检测顺序展示。STDF / ATDF 转换明确标注为晶圆图导出。
- 旧记录和备份可继续使用。重新导入批次、晶圆编号和矩阵一致的数据可补记来源。安装包沿用此前签名，可覆盖升级。
