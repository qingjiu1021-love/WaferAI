# WaferAI 5.2.0

冷启动的油画漩涡从米白画布展开，经历蓄力、扩张、飘带甩出和星夜收束四段，3 秒后过渡到工作台。点按开屏或按返回键可跳过。系统动画缩放关闭时显示 300 毫秒的标志淡入。

`SplashConfig.kt` 集中定义阶段时刻、毛边、扭曲和降级阈值。API 33 起使用 AGSL。早期系统、低内存设备与连续五帧超过 20 毫秒的场景使用位图动画。主界面与资源加载并行进行。开屏是同一 Activity 的临时覆盖层，消失后不留在返回栈。

三张 WebP 位于 `android/app/src/main/res/drawable-nodpi/`。内置图像生成工具制作居中金色太阳、蓝色螺旋和深海军蓝厚涂纹理，打包为 `sun_swirl.webp`。另行绘制金色 S 形、浅蓝色 S 形和蓝金斜刷三条分离笔触，打包为 `stroke_ribbons.webp`。原主题星夜壁纸缩放为 `night_bg.webp`。
