# WaferAI 5.2.2

木画架上的旋心先动，32 道笔触由短到长离开画布，在固定镜位内将画室逐步覆盖成星空。颜料向中央回卷，依次绘出晶圆缺口、厚涂晶圆面、金色网格和星环。最后轻微推近，过渡到主页。开屏全程无字标，可点按跳过。

用内置图像生成工具制作两张纹理，提示分别为「正面固定镜位、木质画架和空白米白亚麻画布、梵高式深蓝画室」及「深蓝厚涂星空、金色旋涡星辰、中央留深蓝暗区」。项目素材位于 `android/app/src/main/res/drawable-nodpi/splash_easel.webp` 和 `android/app/src/main/res/drawable-nodpi/night_bg.webp`。油彩分层与徽章轮廓使用 Compose 绘制。
