# WaferAI 5.3.0 本地测试版

这次更新收紧常用操作路径，移除头像、昵称及相关编辑页面。版本号为 5.3.0，versionCode 为 67。

| Before | After | Why |
| --- | --- | --- |
| 我的页面先展示个人资料、统计和历史入口 | 直接展示常用设置、数据与 AI、帮助与说明 | 减少重复信息，更快找到设置 |
| 晶圆首页使用大幅介绍图、两张功能卡和汇总统计 | 一张开始分析卡，集中提供文件、图片和演示入口 | 首屏突出要执行的操作，最近记录更靠前 |
| 工具页先展示介绍卡，再使用不同大小的入口 | 知识与连接、高级工具两组统一列表 | 降低浏览负担，入口及用途更易比较 |
| 帮助页面仍引导编辑头像昵称 | 介绍新的设置位置和数据页历史入口 | 保持说明与实际功能一致 |

## 保留的工作流

晶圆导入、网格图片识别、演示样本、完整摘要、本地检测、报告、历史记录、文件转换、AI 对话、知识库、插件、轻量模型训练、备份等功能仍可使用。汇总统计在数据页查看，教学仿真与结果回放在晶圆首页的更多工具中进入。

## 后续优化优先级

1. **串起检测流程。** 在导入确认后，提供一个明确的“开始分析”，统一展示统计、本地识别和报告的进度；在线解析作为可选步骤，失败可单独重试。
2. **批量处理。** 允许选择多个文件，显示逐项进度、取消和失败重试，避免一个损坏文件阻塞其他晶圆。
3. **报告阅读模式。** 在图表和长文本页面减弱星夜底图，让良率、异常区域、来源和结论更醒目；保留用户原有主题选择。
4. **按真实设备数据优化流畅度。** 固定冷启动、五页切换、长历史列表及大矩阵缩放的测试路线，再处理耗时最高的环节；补充 Baseline Profiles，并对比优化前后的启动及帧耗时，避免只调整动画时长。
5. **统一结果措辞。** 清楚区分数据集标注、本地模型得分、图片重建和 AI 建议；在结论旁提供简短解释和复核入口。

性能方案参考 Android 官方的 [Macrobenchmark 指南](https://developer.android.com/topic/performance/benchmarking/macrobenchmark-overview)及 [Baseline Profiles 指南](https://developer.android.com/codelabs/android-baseline-profiles-improve)。这两项属于后续工作，本版没有宣称已实现相关性能提升。
