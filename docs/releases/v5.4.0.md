# WaferAI 5.4.0 本地测试版

版本号 5.4.0，versionCode 68，最低 Android 8.0 / API 26。沿用之前的签名，可直接覆盖安装。

## 功能变化

- **四个底部选项卡。** 保留晶圆、数据、AI、工具，移除「我的」。主题、语言、常规设置、备份与恢复、AI 模型管理及关于均在工具页。旧版启动页设置为「我的」时，升级后自动转到工具，其他偏好不重置。
- **选项卡透明度。** 工具 → 主题中可设置 0–100% 透明度，浮动和固定底栏、关闭玻璃效果时均可调节。拖动即时预览，松手保存；标签和选中标记保持可见。
- **一键分析。** 打开单片晶圆后，点击「一键分析并生成报告」，依次核对芯片统计、运行本地 CNN 检测、生成 PDF；显示阶段进度，可取消。成功后直接打开报告。该流程无需网络，不调用付费在线模型。
- **批量分析。** 晶圆工作台右上角的报告图标可多选文件，最多保留 100 项任务。文件逐个处理，显示整体进度和各文件状态；单项失败不会阻塞下一项，支持取消剩余任务、重试失败与取消项。已完成项可查看晶圆及导出已生成的 PDF。
- **报告阅读模式。** 默认减弱报告背景，突出良率结论、缺陷类别和异常位置入口，原有图表、完整摘要及手动导出保留。开关在报告页或工具 → 常规设置中，重启后保留。

## 任务和文件行为

队列会保存到本机。关闭批量面板不会取消正在执行的任务；进程被系统终止后，未完成项会标记为取消，重新打开后可重试。本版不承诺锁屏或系统杀进程后持续后台运算。文件权限失效、文件被移动或删除时，需要重新选择源文件。

统计、识别和 PDF 均在后台线程执行，单片和批量分析共享串行处理锁，避免同时堆积大矩阵和模型内存。取消会保留已经保存的晶圆和已完成的报告；报告使用原子写入，取消生成不会覆盖旧 PDF。取消是协作式的，正在执行的模型推理结束后才会响应取消。

PDF 自动保存在 App 本机目录，可通过导出另存到用户选择的位置。清除任务列表不删除晶圆或已完成报告。卸载 App 会移除内部文件，请将需要保留的 PDF 导出。现有晶圆备份不包含批量队列与自动生成的 PDF；恢复晶圆备份后清除旧队列，避免旧任务指向恢复后的不同记录。检测/导出执行期间禁用恢复操作。

批量流程沿用单文件导入器支持的格式及大小限制。PDF 展示本地识别和统计结果，不代表探针台或 ATE 的真实电性测量；在线 AI 解析仍是用户主动选择的独立操作。

## 流畅度优化

切页期间停止无用的全屏背景层录制；透明度为全透明或全不透明时不再执行背景取样。工具页按需布局，避免首屏同时构建屏幕外的所有分组。完整真机方法、结果、构建差异和限制见 [性能记录](../5.4.0真机性能记录.md)。

## 验证

- 构建、单元测试和 Android Lint 均成功。17 个单元测试类共 54 项通过，0 失败、0 跳过。
- Lint 0 错误、45 项警告、3 项提示；保留的提示包括依赖更新建议、KTX、未用资源及状态装箱，不宣称已消除全部代码提示。
- Pixel 2 / API 36 模拟器：10 项仪器测试通过，包含启动与设置返回、四栏导航、透明度边界、实际离线检测与 PDF、取消时保留原报告、批量失败继续/重试/取消、队列恢复和 PDF 导出。
- 透明度测试在固定底栏且关闭玻璃的情况下验证 0% / 100% 边界；偏好测试验证 0、37、100 的保存及旧版「我的」启动项迁移。
- W20 实际流程得到合格 2145、不合格 315、有效芯片 2460、良率 87.20%、Center 分类；生成 PDF 并进入阅读模式，已保存截图。
- ROG Phone 8 / Android 16：分别完成 5 次冷启动及 5 次四页切换的前后对照；最终用户安装包已覆盖安装，原有记录可读取，四栏与工具设置入口、批量分析面板已检查。
- APK 签名校验通过，证书与此前测试包一致。未清空手机 App 数据。
