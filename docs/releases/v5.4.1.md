# WaferAI 5.4.1 本地测试版

底部导航与页面选项框分别控制透明度，均支持 0–100%。100% 时移除容器底色、高光、边框与阴影，文字、图标和导航选中标记保留。底部导航不再取样模糊背景，直接透出原页面，减少额外图层工作。

工具 → 主题新增「页面选项框」设置，支持无、标准、极致液态玻璃，另有独立透明度滑块。首页开始分析卡、晶圆记录卡、工具入口分组、主题选项及共用内容面板采用清晰透光材质，默认透明度 72%。选择无玻璃时仍可调整底色透明度。拖动实时预览，松手保存；重启后保留，两类透明度互不覆盖。报告阅读模式继续提供安静底幕，图表、图片和文字不随容器变透明。

版本：5.4.1 / versionCode 69。沿用原签名，覆盖安装保留已有数据和设置。

验证：构建、54 项单元测试及 Lint 成功；11 项模拟器仪器测试通过，包含导航与页面透明度边界、两类数值独立、保存恢复、设置导航、启动及分析流程。手动检查开始分析卡与晶圆记录卡透出清晰背景。手机已断开，本版尚未完成真机安装和新增性能测量，5.4.0 的性能数值不作为本版新结果。
