# 历史记录

首页右上角点击“历史记录”，查看已导入晶圆。列表按导入记录编号倒序显示批次、晶圆编号、来源文件、良率、有效芯片数和导入时间。时间转换为北京时间。

点击记录后，直接从后端读取原始矩阵、良率及已有识别结果。未识别过的晶圆保持未识别状态，可手动识别；记录切换时清除上一张晶圆的页面状态，防止旧结果出现在新记录下。已打开的记录也可以继续导出 PDF。

列表使用 `GET /api/v1/wafers?limit=20&offset=...` 接口，每次加载 20 条。只在打开具体记录时请求完整矩阵。刷新从第 1 页重新加载，并取消之前的列表请求；追加数据按记录编号去重。读取失败时提供重试。全局历史的返回按钮及系统返回键回到首页。

从“批次汇总”点入时，页面标题为“批次晶圆”，增加 `lot_id` 查询参数，仅显示该批次记录，并展示该批次全部已保存晶圆的汇总。此时返回按钮及系统返回键回到批次汇总。首页再打开“历史记录”会清除批次筛选。

该功能沿用电脑后端保存的数据，需要连接分析服务，不增加本地数据库或存储权限。

## 本次验证

Android debug 构建通过，已更新当前 Pixel_2 模拟器。使用既有两条记录实测：

- WM811K-lot2 / W20：列表良率 87.20%，打开后显示 53×58 原始矩阵并恢复 Center 识别记录。
- DEMO-001 / W01：列表良率 85.71%，打开后显示 9×9 模拟矩阵，不带入上一张的 Center 结果。
- 返回列表、刷新及系统返回键正常，刷新后仍为两条记录。

上述检查不新增或修改后端晶圆数据。超过 20 条记录的多页 UI 场景尚未实测，分页代码已接入现有接口。
