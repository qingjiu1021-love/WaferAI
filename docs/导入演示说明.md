# 如何导入一张晶圆

1. 保持电脑上的 WaferAI 后端运行，打开模拟器里的 App。
2. 点击“选择 JSON 文件”。已有导入结果时，按钮显示“导入其他文件”。
3. 在系统文件选择器的“最近使用”或“下载”里选择 `demo-wafer-001.json`。
4. 文件选中后自动上传，成功后出现“导入完成，结果已保存”。
5. 向上滑动查看晶圆图和良率：绿色是合格芯片，红色是不合格芯片，灰色是非芯片区域。

这份样例是模拟数据，不是生产实测数据或 WM-811K 数据。结果应为：合格 42、不合格 7、有效总数 49、良率 85.71%。

样例原文件：`E:\WaferAI\data\samples\demo-wafer-001.json`。

同一文件可再次导入，系统会打开已有记录而不新增重复记录。要试改矩阵，请同时将 `wafer_code` 改为新的编号，如 `W02`，以免覆盖原记录。

当前仅支持 JSON。CSV 导入和 CNN 分类留到后续阶段。
