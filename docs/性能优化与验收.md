# 4.9.0 性能优化与验收

本轮针对界面线程上的矩阵遍历、重复统计和过大的状态订阅范围进行优化，保留原有主题、液态玻璃和开启动画设置。未改变 CNN 权重、良率公式、分区边界或四连通定义。

## 实现

1. WaferReportData 在一次遍历中统计行、列、分区和芯片数。WaferSummary 保存报告数据和聚集结果，晶圆报告复用它们，不再次计算。异常索引使用 IntArray，避免逐芯片创建中间列表。
2. 图像和坐标在 Dispatchers.Default 准备；矩阵缓存键采用对象身份，避免 UI 状态比较时深度扫描所有芯片。更换矩阵、主题、筛选或高亮时校验结果所属请求，避免旧位图闪现。
3. 手势状态在绘图阶段读取，缩放控件单独订阅；仅遍历可见网格线。点击发现时的大范围边界计算也在后台执行。
4. 主界面只订阅聊天是否忙碌，输入内容由聊天页订阅。每条消息的 ID 使列表保留项目身份；兼容缺少 ID 的旧记录。计时器只更新自身，消息正文的清理结果继续缓存。
5. 训练模型恢复由 ImportViewModel 发起后台读取，并在训练和预测入口确保只加载一次。构造仓库不再反序列化训练样本。

## 验证范围

- 45 项 JVM 测试，包括随机稀疏矩阵和最大 512×512 矩阵统计与独立计数对照、身份键不触发深度读取、旧消息 ID 升级和保留最近三十轮时的标识稳定性。
- 模拟器测试覆盖最大矩阵的后台读取、双指缩放、芯片点选、相同记录 ID 更换矩阵后位图更新、三十轮长对话滚动与输入、真实样本高亮和清除、训练保存和重新载入、图表逐行逐列切换。
- 未测量真机 FPS、长时间发热或功耗，不给出帧率或耗电提升比例。当前沿用既有测试包签名与构建类型；并非经过 R8 优化的正式发布构建。
- 详细通过数量和 APK 校验信息见 artifacts/WaferAI-4.9.0-validation.json。功能测试使用隔离数据，不覆盖已有记录。
