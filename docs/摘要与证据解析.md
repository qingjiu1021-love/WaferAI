# 摘要与证据解析

## 本地自动摘要

参考 wafertools Summary / Findings 的交互方式，采用 WaferAI 原始矩阵统计，不复制其统计检验算法，也不宣称统计显著性。导入及历史查看均自动计算，断网可用；不修改输入、分类标签或既有记录。

统计针对整张晶圆。分区沿用矩阵归一化半径0.35/0.70，最高不合格率区域展示分子和分母。聚集区按上下左右邻接统计，选中最大区时高亮实际成员而非外接矩形。阈值是用户当前参考设置；不是工艺规格限。筛选只改变地图显示，不改变摘要统计。清除高亮会恢复普通视图；高亮状态不写入主题筛选偏好。

## AI 模板和核对边界

四种模板改变表述重点及待验证原因、步骤的数量上限，不改变原始统计。模板选择随已有主题设置持久保存，恢复默认时重置为工程排查。

程序生成带ID的事实登记表：整片统计、分区、最大聚集区、行列峰值以及模型输出。模型只能选择已有事实ID，数字由程序渲染；其自由文本不得生成数值或百分比。回复须满足限定字段和数量，不能引用不存在的事实或来源。非法回复不保存，也不会覆盖既有解析；不自动进行额外收费重试。

这是一种受限结构与数值引用校验，不是语义正确性、根因真实性或概率校准的保证。模型可以给出待验证解释，仍需人工结合电测及工艺记录复核。原始标签、CNN得分与观测事实始终分别解读。得分不等同于正确率。

解析可读取最多3条匹配的本地知识资料；公开示例的单片事实条目排除在检索材料外，避免把其他样本数值当成本片观测。参考资料被标记为不可信数据，禁止执行其中的指令。只发送统计、分类摘要与所匹配的知识条目；不发送原始矩阵、导入文件名或账号密钥到模型正文。API密钥按既有方式用于请求认证。

通过校验的解析以可读文字保存在已有数据库，包含所用模板、原始事实和引用链接，因此现有历史、备份与PDF导出继续可用；旧解析继续可读，不追溯标记为已核对。暂不改变数据库结构及已冻结CNN。

## 验证范围

本地摘要、聚集区真实成员、全合格/全不合格/稀疏网格、非法结构和编号、数字及百分号拦截、模板与引用渲染均有针对性测试。在线流程使用模拟接口验证请求与回复约束；实际模型仍需使用用户自己的网络和有效API配置验收。一般自由聊天不采用此专用解析协议。
