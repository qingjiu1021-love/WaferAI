# WaferAI

题目：基于 Android 的集成电路晶圆缺陷智能识别与良率分析系统设计与实现。

## 当前阶段

Android App 已接入 FastAPI 健康检查及 JSON 文件导入。导入后显示原始晶圆图、芯片数量和良率，记录保存到 SQLite，原始矩阵保存为 uint8 NPY 文件。

已完成 WM-811K 数据清洗、批次划分和首版 CNN 训练。独立测试集 24,219 张晶圆，accuracy 96.85%、macro-F1 0.8345。CNN 已接入 FastAPI 和 Android 的“识别缺陷类型”按钮，识别结果保存到 SQLite。首页“历史记录”可直接打开已保存晶圆并恢复识别结果。“批次汇总”可查看各批次的晶圆数量、芯片合计和总体良率，并打开对应晶圆。芯片良率独立由原始矩阵计算，App 支持将当前晶圆和识别结果导出为 PDF 报告。剩余重点为真机联调和交付检查。

Android 1.1 新增“服务设置”：可选模拟器、USB 连接或自定义电脑地址；先验证 WaferAI 接口再保存，重启后保留设置。切换服务清空当前晶圆及列表页面，避免混用不同服务的记录。首页自动检查连接并显示失败原因。手机连接流程见 `docs\手机连接与服务设置.md`。

## 在当前电脑启动

1. 双击 `E:\WaferAI\backend\start-backend.bat`，保留服务窗口。服务已经启动时无需重复启动。
2. Android Studio 打开 `E:\WaferAI\android`，等待 Gradle 同步完成。
3. 启动模拟器并运行 `app`，点击 App 内的“检查服务”。
4. 把 `data\samples\demo-wafer-001.json` 放入模拟器的“下载”目录，然后点击“选择 JSON 文件”并选中它。
5. 真实数据演示使用同目录的 `wm811k-center-001.json`，导入后点击“识别缺陷类型”。识别结果和模型版本会保存，原始良率不变。
6. 点击“导出 PDF 报告”，在系统窗口选择 Downloads 等保存位置，点击 SAVE。操作与验证记录见 `docs\PDF报告导出说明.md`。
7. 首页“历史记录”可查看和打开已有晶圆，支持刷新与分页，详见 `docs\历史记录说明.md`。
8. 首页“批次汇总”显示已导入晶圆的批次统计，点击批次查看明细。总体良率采用总合格芯片数除以总有效芯片数，详见 `docs\批次良率汇总说明.md`。
9. 首页右上角“服务设置”可修改地址，选择“模拟器连接”后点击“检查并保存”即可恢复当前电脑的模拟器连接。

## 导入格式与演示

演示样例是手工构造的模拟数据：9×9 矩阵、42 个合格芯片、7 个不合格芯片、49 个有效芯片，良率约 85.71%。

JSON 包含 `lot_code`（批次号）、`wafer_code`（晶圆编号）、`map`（二维矩阵）。0 表示非芯片区域、1 表示合格芯片、2 表示不合格芯片。非芯片区域不参与良率分母。

当前支持 UTF-8 JSON（含 BOM），文件不超过 2 MB，矩阵行列各不超过 512。各行列数必须相同，矩阵元素必须为整数 0、1、2，至少包含一个有效芯片。

相同批次和编号重复导入相同矩阵会打开已有记录；同一编号使用不同矩阵会提示冲突。修改样例矩阵时请使用新的晶圆编号（如 W02）。

接口：`POST /api/v1/imports`，multipart 文件字段为 `file`；`GET /api/v1/wafers` 查询记录，`GET /api/v1/wafers/{id}` 查询完整矩阵和统计。

批次：`GET /api/v1/lots?limit=20&offset=0` 查询批次统计；`GET /api/v1/lots/{id}` 查询单个批次；`GET /api/v1/wafers?lot_id={id}` 查询对应晶圆。批次统计涵盖该批次全部已保存晶圆，与当前列表分页无关。

识别：`POST /api/v1/wafers/{id}/predictions`；已保存结果：`GET /api/v1/wafers/{id}/predictions/latest`。模型目录为 `artifacts\serving\cnn-v1`，可用环境变量 `WAFERAI_MODEL_DIR` 指定其他已准备目录。完整接口、新增数据表和联调记录见 `docs\CNN接口与结果保存.md`。

数据保存在 `E:\WaferAI\storage\waferai.db` 和 `storage\maps\`，不要只备份 APK。

电脑上的接口：`http://127.0.0.1:8000/api/v1/health`。
接口文档：`http://127.0.0.1:8000/docs`。

App 默认使用 `http://10.0.2.2:8000/` 连接 Android 官方模拟器。USB 手机在电脑运行 `backend\连接手机.bat` 后，App 服务设置选择“USB 连接”，使用 `http://127.0.0.1:8000/` 经过调试通道访问电脑。普通启动入口仍仅监听本机。

同一局域网的 Wi-Fi 手机可使用 `backend\start-backend-lan.bat`，并在 App 填写电脑的 IPv4 地址。此方式需要先停止占用 8000 端口的普通服务；不要同时启动两个入口。具体步骤及验证范围见 `docs\手机连接与服务设置.md`。当前 APK 是演示调试版，模型和数据库仍在电脑端。

关闭服务：在自己打开的服务窗口按 Ctrl+C。

## 后端环境与数据准备

### 本机 WM-811K 样例转换

原始数据放在 `E:\WaferAI\data\raw\wm811k\LSWMD.pkl`。在 `backend` 目录执行：

```bat
.venv\Scripts\python.exe -m pip install -r requirements-data.txt
.venv\Scripts\python.exe scripts\export_wm811k_sample.py
```

运行转换脚本后，生成一张保留原始矩阵的 `Center` 晶圆 JSON：`data\samples\wm811k-center-001.json`，可用现有 App 的 JSON 导入功能验证。来源和原始标签记录在同目录下的 `metadata` 文件夹。来源标签用于离线核对，App 识别结果由模型根据矩阵单独生成。

### CNN 数据准备

GPU 环境采用 PyTorch 2.10.0+cu126，划分工具采用 scikit-learn 1.7.2。训练相关依赖见 `backend\requirements-training.txt`。在 `backend` 目录执行：

```bat
.venv\Scripts\python.exe scripts\prepare_wm811k.py
```

执行前停止模拟器并关闭 Android Studio，给 2 GB 原始数据的读取留出内存。脚本排除空标签、校验矩阵、处理重复输入和标签冲突，并按批次生成固定划分。输出到 `data\processed\wm811k-v1`，不覆盖已有版本，不修改原始文件。详细方法及许可记录见 `docs\WM811K训练数据准备.md`。此命令不训练模型。

### CNN 训练试跑

在 `backend` 目录执行：

```bat
.venv\Scripts\python.exe scripts\train_cnn.py --epochs 1
```

使用小型 CNN 完整试跑训练集和验证集，按验证集 macro-F1 保存模型，测试集留待最终评估。输出到 `artifacts\cnn-runs\trial-日期-时间`。训练设置和文件说明见 `docs\CNN训练说明.md`。训练命令不自动替换后端模型，当前服务仍使用已测试的 cnn-v1。

### 初始化 API 环境

在 `backend` 目录执行：

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-api.lock.txt
start-backend.bat
```

新电脑还需通过 Android Studio 配置本机 JDK 与 Android SDK。`.venv`、`local.properties` 和构建缓存不应复制进版本库。

## 项目结构

```text
android/app/src/main/java/com/example/waferai/
  AppContainer.kt                手动提供网络服务和 Repository
  WaferAiApplication.kt           App 级容器
  data/remote/WaferApi.kt         Retrofit 接口与响应对象
  data/repository/                数据访问
  data/report/                    Android 原生 PDF 报告生成与数据快照
  ui/connection/                 页面与 ViewModel
  ui/importdata/                 系统文件选择、导入状态、晶圆图和良率
  ui/history/                    历史列表、分页刷新和记录打开
  ui/lots/                       批次统计列表、汇总卡片与晶圆筛选
  ui/settings/                   服务地址编辑、验证与保存
backend/
  app/main.py                    健康检查接口与响应约定
  app/schemas.py                 JSON 数据校验和响应模型
  app/models.py                  SQLite 四张表及关系
  app/wafer_store.py             事务保存、原始矩阵和重复导入处理
  app/ml/                       共享预处理、小型 CNN、数据准备与训练
  app/prediction_service.py      CNN 识别结果保存、缓存及查询
  tests/test_imports.py           数据校验与保存的自动测试
  tests/test_lots.py              批次加权统计、筛选和大整数测试
  requirements-api.txt            直接依赖
  requirements-api.lock.txt       实际安装版本
  requirements-data.txt           WM-811K 转换所需的依赖
  requirements-training.lock.txt  当前 API 与训练环境的完整版本记录
  scripts/export_wm811k_sample.py  导出一张原始晶圆用于 App 导入演示
  scripts/prepare_wm811k.py        清洗、去重并按批次固定划分数据
  scripts/train_cnn.py             首版 CNN 训练与验证
  scripts/evaluate_cnn.py          冻结模型的独立测试与结果保存
  scripts/connect_phone.py         USB 手机检查、安装及端口连接
  start-backend.bat               本机启动入口
  start-backend-lan.bat           同局域网手机演示入口
  连接手机.bat                    USB 手机连接入口
```

本地 HTTP 访问仅在 Android debug 配置中启用。正式联网部署时配置 HTTPS 地址。
