## 4.3.0 账号管理补充

“我的 → 账号”支持添加和切换多个已登录账号；会话加密保存在设备中，切换前联网验证。过期账号从本机列表移除，需要重新登录；其他有效账号不受影响。退出只退出当前账号；“移除”只清除本机会话，不注销服务器账号。

手机号与邮箱分别支持新增一种已验证联系方式。绑定需在登录后 15 分钟内完成，验证码限定当前用户与目标，不能用注册验证码替代，也不能把其他账号的联系方式直接合并。绑定时设置此登录方式的密码，既有密码不变。未配置发送服务时入口说明未开通，不伪装发送成功。

新增接口：POST /api/v1/auth/bind/codes（Bearer token，target）；POST /api/v1/auth/bind（Bearer token，target、code、password）。FastAPI 与线上 D1 服务均支持。原有身份密钥和数据库保持不变，无需迁移。

“我的 → 关于 → 检查版本更新”读取 GitHub 正式版本，校验仓库、版本编号与 APK 信息，由用户确认下载。发布步骤见 GitHub发布与更新.md。

# WaferAI 4.2.0 账号与帮助中心

## 已部署的在线服务

入口为 https://waferai-help.sparsefirefly.chatgpt.site/account 。帮助内容在 `/help`，由服务端校验 WaferAI 会话，未登录会返回账号页。站点入口公开，使用条款与隐私政策无需登录。

新版 App 默认连接该在线服务，未登录的旧版本机测试地址会迁移到在线地址，已有登录及自定义服务配置保留。也可在账号服务设置切换。云端与本机开发数据库相互独立，不会上传或合并本机测试账号、晶圆、聊天、训练样本或模型密钥。

线上提供 ChatGPT 授权登录：勾选政策同意后选择该入口，在系统浏览器完成托管平台授权，再返回 App。网页可直接完成相同授权。授权进度加密保存在设备，重启 App 后可继续等待，断网会重试，取消或过期会停止本次登录。

微信、QQ、Facebook、Telegram 的浏览器授权适配已实现，但目前没有对应的真实应用凭据，因此显示“尚未开通”。没有虚构平台应用或测试用户登录。邮箱和手机号同样需要维护者开通发送服务，线上没有开发收件箱和固定验证码。

托管实现位于 `help-site/`，Sites / Cloudflare 运行服务端路由并使用 D1 保存账号数据；原 Python FastAPI 版本仍可在自己的服务器部署。项目身份和部署绑定在 `help-site/.openai/hosting.json` 中，不要重新创建站点。站点生产密钥保存在托管平台，不在源码或安装包里。

云端邮箱使用 `WAFERAI_RESEND_KEY` 和 `WAFERAI_EMAIL_FROM`；手机号使用 `WAFERAI_SMS_URL/TOKEN` HTTPS 适配器。四个平台仍使用下文的 `WAFERAI_<平台>_ID/SECRET`，回调地址按线上域名填写。配置变更需要部署新环境版本后生效。

本次线上验证包括公开账号页、匿名帮助重定向、匿名账号接口拒绝访问、托管登录跳转以及伪造身份头拒绝访问。完整授权会话在本地预览验证；没有替用户输入真实第三方账号密码或完成平台审核。

模拟器实测通过了线上账号服务连接与 ChatGPT 入口显示。测试电脑通过本机代理上网，模拟器原网络不能解析该域名；临时共享电脑的既有网络路径后连接成功，验证后恢复模拟器原设置。真实手机需要能访问该站点和相应授权平台，当前尚未进行真机授权验收。自动审批拒绝了直接打开模拟器浏览器的验证命令，仅返回 `blocked by policy`，因此未代用户完成浏览器中的真实账号授权。

## 先在本机测试

1. 安装 `artifacts/WaferAI-4.3.0.apk`，覆盖安装即可。
2. 若本机尚未安装新依赖，在 `E:\WaferAI\backend` 执行：

   ```powershell
   .venv\Scripts\python.exe -m pip install --index-url https://pypi.org/simple -r requirements-account.txt
   ```

3. 双击 `E:\WaferAI\启动账号测试服务.bat`，保留该窗口。若提示端口占用，先确认是否已有测试服务，不要重复启动。
4. 模拟器进入“我的 → 登录 / 注册 → 账号服务设置”，填写 `http://10.0.2.2:8010`，点击“保存并检查服务”。这是模拟器访问开发电脑的地址。
5. 选择“注册”，填写虚构测试邮箱，例如 `reader@example.invalid`、昵称和密码。密码需 10–128 位，包含字母和数字。
6. 阅读使用条款、隐私政策后勾选同意，再获取验证码。本机测试模式不会发送真实邮件或短信。在开发电脑查看 `E:\WaferAI\storage\accounts\development-outbox.jsonl` 中对应测试账号最新验证码，填回 App 完成注册。不要分享这个文件。
7. 登录后可打开帮助中心，网页会验证登录状态。退出 App 再打开，登录会话仍保留，默认 7 天后失效。可从账号页退出、仅移除本机登录状态或注销账号。
8. “找回密码”使用同一邮箱或手机号获取 `reset` 用途验证码。重置后旧会话失效，需使用新密码重新登录。

浏览器也可以在 `http://127.0.0.1:8010/account` 注册、登录并进入帮助中心。直接访问 `/help` 的未登录用户会被送往登录页。政策页面无需登录。

手机 USB 联调时先执行 `E:\Android\SDK\platform-tools\adb.exe reverse tcp:8010 tcp:8010`，App 的账号服务地址用 `http://127.0.0.1:8010`。手机拔线后，本机账号服务不可达；正式使用必须配置公网 HTTPS 服务。

## 正式接入配置

示例为 `backend/.env.accounts.example`。示例不含真实密钥。把值设置到服务进程环境，不要放进 APK、源码或聊天。示例文件不会被启动脚本自动读取。测试启动脚本固定开启开发收件箱，不能用于正式部署。

- 公开地址：`WAFERAI_AUTH_PUBLIC_URL=https://你的账号域名`，`WAFERAI_AUTH_DEV_OUTBOX=0`。正式服务应使用 HTTPS 反向代理、受控的数据目录与备份，并关闭访问日志中的敏感查询参数。
- 邮箱：配置 `WAFERAI_SMTP_HOST/PORT/FROM/USER/PASSWORD`。465 使用 TLS，其他端口要求 STARTTLS，不降级为明文发送。
- 手机号：配置 `WAFERAI_SMS_URL` 和 `WAFERAI_SMS_TOKEN`。它是你控制的 HTTPS 短信适配服务，后端向其 POST `{phone, code, purpose, expires_in}`，返回 `{accepted:true}` 才算发送成功。可在该适配层接入已有的阿里云、腾讯云等短信账号；本版没有替你开通或验证这些供应商。
- 微信：`WAFERAI_WECHAT_ID/SECRET`，使用已审核的网站应用扫码授权和服务端 code 换取身份。当前不是原生微信 SDK 拉起登录，需要网站应用权限和回调域名。
- QQ：`WAFERAI_QQ_ID/SECRET`，使用网站应用 OAuth，在系统浏览器完成授权，不在内嵌 WebView 中授权。
- Facebook：`WAFERAI_FACEBOOK_ID/SECRET`，使用 Facebook Login 授权和服务端身份验证，需要开发者应用权限与正确的重定向地址。
- Telegram：`WAFERAI_TELEGRAM_ID/SECRET`，使用 BotFather Login Widget 配置中的 Client ID/Secret，授权码 + PKCE 流程，服务端验证 RS256 签名、issuer、audience、过期时间和 nonce。BotFather 须允许该回调 URL。

各平台回调 URL 都是 `https://你的账号域名/auth/social/{provider}/callback`，provider 分别为 `wechat`、`qq`、`facebook`、`telegram`。所有开发者账号、应用审核和真实凭据均需自行申请；未配置渠道会显示“尚未开通”。测试使用模拟平台响应验证协议，不表示已完成真实平台授权。

第三方首次授权自动创建账号。不会仅凭邮箱相同就合并账号，避免误绑定。当前未提供账号绑定、解绑和跨账号云同步。

独立服务不加载 PyTorch：

```powershell
.venv\Scripts\python.exe -m uvicorn app.account_app:app --host 127.0.0.1 --port 8010 --no-access-log
```

原 `app.main:app` 也挂载相同账号路由，可在已有 API 服务中提供账号功能。账号数据保存在 `storage/accounts/`，包含数据库及服务签名密钥，迁移时应一并安全保管。不要把开发收件箱、数据库和签名密钥发布到静态网页目录。

## API 与网页

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/auth/capabilities` | 可用渠道和测试模式状态 |
| POST | `/api/v1/auth/codes` | 发注册或重置验证码，60 秒冷却 |
| POST | `/api/v1/auth/register` | 验证邮箱或手机号，创建账号并登录 |
| POST | `/api/v1/auth/login` | 邮箱或手机号 + 密码登录 |
| POST | `/api/v1/auth/reset-password` | 验证码重置密码并撤销旧会话 |
| GET | `/api/v1/auth/me` | 当前身份 |
| POST | `/api/v1/auth/logout` | 撤销当前会话 |
| DELETE | `/api/v1/auth/account` | 注销账号，保留本机工作空间 |
| POST | `/api/v1/auth/social/start` | 创建第三方授权请求 |
| POST | `/api/v1/auth/social/poll` | 使用独立的短期凭据领取登录结果 |
| POST | `/api/v1/auth/web-session` | 创建仅可使用一次、60 秒有效的网页登录链接 |
| GET | `/help` | 登录后可访问的常见问题网页，支持搜索 |
| GET | `/account` | 网页注册、登录、找回密码 |
| GET | `/legal/terms`、`/legal/privacy` | 公开政策页面 |

密码采用加盐 scrypt；验证码、会话令牌和短期凭据在数据库内使用 HMAC 摘要。Android 登录令牌由 Keystore 支持的加密存储，并排除系统云备份与设备迁移。网页会话使用 HttpOnly Cookie。账号服务不记录完整请求、密码或验证码；开发收件箱是明确开启的本机测试发送器。

## AI 自由对话

在线模型的系统提示词支持生活、学习、写作、编程、翻译与晶圆分析。空白对话的快捷问题也按模型类型区分。晶圆摘要只在主动附带时作为资料，不强制给普通问题添加晶圆背景。

离线“基础助手”仍是规则 + 本机知识检索，并未假装成通用大模型；自由聊天请选择自己配置的在线模型。没有真实模型 API 凭据时只能验证请求结构，不能承诺第三方回答效果。
